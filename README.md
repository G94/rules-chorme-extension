# Regla de lectura (extensión de Chrome)

Esta extensión muestra una regla horizontal que sigue el cursor para ayudar en la lectura y concentración.

## Uso

1. Abre `chrome://extensions`.
2. Activa **Modo desarrollador**.
3. Haz clic en **Cargar sin empaquetar** y selecciona esta carpeta.
4. Abre el popup de la extensión y activa la regla.
5. Ajusta altura, color, opacidad o define una imagen por URL.

> Para seguir la lectura, mueve el cursor y la regla se desplazará con él.
